# Package contents

## Included
- Canonical and sensitivity optical input tables.
- Radar input/reduction tables and source capture.
- Frozen Tudat configuration and environment specifications.
- Core orbit-fitting, model comparison, LOO, weight-sensitivity, radar, correlated-likelihood, robustness, and selected harmonisation source code.
- Baseline model parameters/summaries/residuals.
- Temporal-support, bootstrap, nonlinear-correlation, cross-code, radar, and clean harmonisation outputs.
- Machine-readable current main-paper tables.
- Six final vector PDF figures plus source CSV/JSON and plotting scripts.
- Scientific claim boundary, software/ephemeris provenance, data dictionary, reproducibility-level notes, and SHA256 manifest.
- Zenodo/CITATION metadata templates and license decision notes.

## Explicitly excluded
- Manuscript PDF.
- Manuscript LaTeX/source/bibliography.
- Supplementary manuscript PDF/LaTeX.
- Highlights, cover letter, journal style/class files.
- Failed/support-confounded internal diagnostic branches that are not part of the final scientific narrative.
- OrbFit executable/source installation and large/native third-party ephemeris binaries.
